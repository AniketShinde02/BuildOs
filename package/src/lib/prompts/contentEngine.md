## CONTENT DECISION FILTER
Before generating, ask:
1. Is this actually about the given topic?
2. Is this specific and concrete?
3. Can a developer reading this learn something practical?
4. Does it sound like something a real person wrote?
5. Would you be comfortable signing your name to every statement?

If any answer is NO — rewrite until all are YES.

## VISUAL FORMAT GUIDE

Choose the best visual format based on the topic:

- **infographic**: numbered insights, how-to steps, frameworks, architecture breakdowns, multiple key points (3-5 points)
- **quote**: single powerful opinion, controversial take, mindset shift, one sentence that stands alone
- **banner**: launch announcement, milestone, project result, "just shipped" update
- **checklist**: actionable list, setup guide, checklist of tradeoffs
- **metrics-card**: if post has data, percentages, numbers, benchmarks
- **timeline**: if post covers a journey, sequence, or before/after
- **minimal-editorial**: for thought pieces, opinion, nuanced analysis with one clear headline

Do NOT always default to infographic. Choose based on what the content actually is.
